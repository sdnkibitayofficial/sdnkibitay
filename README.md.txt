# SDN Kibitay Sukabumi — Website Resmi

Website resmi **SDN Kibitay Sukabumi**, sebuah Sekolah Dasar Negeri di Kecamatan Lembursitu, Kota Sukabumi, Jawa Barat.

## Cara Upload ke GitHub Pages

1. Buat repository baru di github.com — nama: `sdnkibitay`, visibilitas: Public
2. Upload 4 file: `index.html`, `sitemap.xml`, `robots.txt`, `README.md`
3. Settings → Pages → Branch: main, Folder: /(root) → Save
4. Tunggu 1-2 menit, website live di: `https://<username>.github.io/sdnkibitay/`
